# gate4ai/sync

Клиент синхронизации файлов с сервером gate4.ai — трей-приложение под Mac, Windows и Linux.

Заменяет сторонний плагин Obsidian remotely-save: работает как отдельный процесс, не зависит
от того, запущен ли Obsidian, синхронизирует произвольные локальные папки по WebDAV.

Постановка задачи и обсуждение — issue [gate4ai/server#38](https://github.com/gate4ai/server/issues/38).
